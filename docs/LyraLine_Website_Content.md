## Page 3: 世界观页（World）

> 设计方向：长滚动叙事页，图文交替，像翻阅一本设定集。节奏是"看一段画 → 读一段文字 → 再看一段画"。不要一次性把所有设定倒出来，留白和节奏很重要。

---

`[全屏视觉：废墟中植物蔓延的场景概念图，上方叠加半透明文字]`

```
文明が沈黙した後も、音だけが残り続けた。
文明沉默之后，唯有声音留存。
```

---

然而，声音留了下来。
在损坏的机械里，在风化的存储介质中，

### Section 4: 共鳴線という名前

```
共 ── 分野を越えて集まり、共に物語を創ること
鳴 ── 音や響き、そこから広がる音楽的表現
線 ── 線として可視化される、ビジュアルと物語
```

```
異なる表現が重なり合いながら、
ひとつの世界観へと収束していく。
その創作のプロセスそのものが「共鳴線」です。
```

不同的表现相互交织，
汇聚成一个世界观。
这个创作过程本身，就是"共鳴線"。

```
共鳴線は、オリジナル楽曲を核に、
キャラクター・ビジュアル・世界観を組み合わせた
マルチメディア企画です。

楽曲一つ一つを独立した作品として成立させながら、
最終的にはひとつの世界観の中で連なっていく構造を目指しています。

長く記憶に残る作品と、
```

每一首乐曲作为独立作品存在，
同时最终在一个统一的世界观中相互串联。

在短视频和一次性内容成为主流的今天，
创作能长久留在记忆中的作品，
与观众建立持续的情感联结，
是我们的出发点。

### 展开阶段

> 用简洁的时间线或卡片形式呈现三个阶段：

```

・動画サイトでの基盤視聴者層の形成

```

```
・物語性を持つシリーズ楽曲の展開
・キャラクター・世界観の深化と拡張
・年間約4〜6曲の音楽映像作品
・コアファン層の獲得と定着
```

```
Phase 3 ── 協業展開期
期間：長期

・マルチメディアIP展開（ゲーム・バーチャルキャラクター・映像）
・ライブ、ポップアップストア、美術展などのイベント展開
・商業連携の段階的導入
```
